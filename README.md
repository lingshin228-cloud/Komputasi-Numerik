## 💡 Prinsip Dasar Komunikasi
Dosen tipe tegas sangat menghargai efisiensi waktu, tanggung jawab mahasiswa, dan penggunaan tata bahasa yang baik. 
* **To-the-point:** Langsung ke inti masalah tanpa bertele-tele.
* **Bertanggung jawab:** Tidak menyalahkan keadaan atau sistem secara defensif.
* **Solutif:** Menawarkan diri untuk memperbaiki keadaan.
